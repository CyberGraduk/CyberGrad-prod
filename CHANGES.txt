CyberGrad — V2.4 Changes
========================
Date: May 2026

ROOT CAUSE FIX — Generic PDF priorities

The problem: cv-checker.html was sending categories to the PDF API
with only {name, score, max} — stripping out the items array entirely.
So the PDF had no desc or fix text to show, falling back to whatever
generic text was hardcoded in send-report.js.

THE FIX (cv-checker.html line ~1040):
categories now sent with full items array:
  categories: cvResults.categories.map(c => ({
    name, score, max,
    items: c.items.map(i => ({ status, title, desc, fix }))
  }))

desc = what was actually found in this student's CV
fix  = the specific action for this student's CV

PDF PRIORITY SECTION (send-report.js):
Each priority fix now shows 3 layers:
1. Title (bold) — the check that failed
2. Finding (grey) — what was actually found/missing in THIS CV
3. Fix: (teal prefix) — the specific action for THIS CV

This means:
- Student with 2 keywords sees: "Only 2 of 18 SOC Analyst keywords found..."
- Student with 0 keywords sees: "Zero SOC Analyst keywords detected. Auto-rejected..."
- Not the same generic message for everyone

Also: role sent in payload for PDF header context.

FILES CHANGED
- cv-checker.html (categories payload fix, priorities to 6)
- api/send-report.js (priority section shows desc + fix separately)
