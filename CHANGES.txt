CyberGrad — V1.5 Changes
========================
Date: May 2026

MAIN FIX — PDF EMAIL (send-report.js)
- api/send-report.js completely rewritten
- Now generates a real branded A4 PDF using pdf-lib
- PDF includes: CyberGrad header, big score, band label, student name/uni/email,
  category breakdown with progress bars, priority fixes list, CTA block, footer
- PDF attached to Resend email as CyberGrad-CV-Report-[Name].pdf
- HTML email body also sent with same summary (score, categories, fixes, CTA)
- Student gets: instant results on screen + PDF in inbox

PACKAGE.JSON ADDED
- pdf-lib v1.17.1 added as dependency
- @pdf-lib/fontkit added
- Vercel installs these automatically on deploy
- Node 20.x specified

FILES CHANGED
- api/send-report.js (full rewrite)
- package.json (new file)

DEPLOY INSTRUCTIONS
1. Copy api/send-report.js and package.json into your repo
2. git add . && git commit -m "V1.5 — PDF email" && git push
3. Vercel will install pdf-lib automatically (takes ~30 seconds longer to build)
4. Test: go to cv-checker.html, paste CV, fill gate form, submit
5. Check inbox — you should receive email with PDF attached

IF PDF FAILS
- Check Vercel function logs: Vercel → project → Functions tab → send-report
- Common issue: pdf-lib not installed → check package.json is in repo root
- Resend attachment limit: 40MB — our PDFs are <100KB so no issue
