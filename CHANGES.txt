DROPDOWN FIX — ALL PAGES
- Changed from hover-only to click-toggle on all pages
- .dropdown:hover .dropdown-menu replaced with .dropdown.open .dropdown-menu
- initDropdowns() JS added: click to open, click anywhere else to close
- Works on mobile, tablet, and desktop
- Pages fixed: index, pricing, cv-checker, signup, login, checkout, success, about, sectors, roles

SECTORS & ROLES — GATE LOGIC FIXED
- No longer redirects to signup.html on click
- Instead shows an inline "Free with a CyberGrad account" screen
- Screen shows: lock icon, explanation, Create free account + Log in buttons
- Content remains hidden (opacity:0) until session check completes
- If logged in: content fades in smoothly
- If not logged in: gate screen fades in instead
- Dashboard cards link to these pages — logged-in users go straight to content

FLOW SUMMARY

- Creates account -> logs in -> dashboard shows Sectors & Roles cards
- Clicks from dashboard -> content shows immediately (session already active)
