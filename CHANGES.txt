CyberGrad — V3.7 Changes
========================
Date: June 2026

FIX 1 — Logout fully clears session
  sb.auth.signOut({ scope: 'local' }) clears local session only
  All localStorage keys starting with sb-, supabase, cg_user, cg_cv_score cleared
  Redirects to login.html
  login.html no longer auto-redirects existing sessions — only redirects on fresh SIGNED_IN event
  This allows switching between users after logout

FIX 2 — CV Checker full report not showing
  Root cause: getSession() was async but runAnalysis() fired before it resolved
  loggedInUser was null when user clicked Analyse despite being logged in
  Fix: checkSession() runs on page load as async function
  runAnalysis() waits for session if not yet resolved
  Full report now shows correctly for logged-in users

FIX 3 — CV Score saving to Supabase
  autoUnlockForLoggedInUser now fetches fresh session for upsert
  Score saved to students table with correct email from live session
  localStorage backup always set

FIX 4 — Dashboard "Unlock with Foundation"
  Changed to "Unlock with Industry-Ready"
  Removed repeated description text
  Price updated to £125 everywhere on dashboard
  
FIX 5 — Hello name not working (TC-02 existing user login)
  checkSession() now checks localStorage cg_user first (fastest)
  Falls back to user_metadata, then students table
  userData.name populated before analysis runs

VERSION TAG — v3.7 is live

FILES CHANGED
- dashboard.html (logout fix, unlock text, price fix)
- cv-checker.html (session timing fix, score save fix)
- login.html (no auto-redirect on existing session)
- index.html (version tag)
